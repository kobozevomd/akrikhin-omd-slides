# Отчёт пользователю

На языке пользователя (по умолчанию по-русски), коротко, без воды. Структура, проверенная на серии дек Акрихин:

**Новая дека (сценарии A и C)**

1. Одна-две фразы: обе версии готовы, файлы приложены; открываются без ошибок; в английской нет русского текста,
   кроме логотипа и креативов на картинках. Если файл > 30 МБ (видео) — сказать, что на телефон не уйдёт, только в приложении.
2. **Что сделано** — 3–6 пунктов: сколько слайдов (и какой разбит на два и почему), сколько слайдов-картинок пересобрано
   живым текстом, видео (сколько, побайтно как в исходнике), скрытые остались скрытыми, единые цвета брендов/этапов,
   EN прошла перевод → редактор → вычитку носителем.
3. **Мои правки, проверьте** — всё, что поменяли по смыслу или по данным: восстановленные искажения генератора, исправленные
   подписи (например длительность ролика), переподписанные ряды графиков, изменения цветовой логики, пропущенный текст.
4. **Цифры исходника, которые не сходятся (оставил как есть)** — по слайдам, с конкретными числами «написано X, по данным Y».
5. **По английской версии уточнить у клиента** — латинские написания брендов/конкурентов/имён, спорные термины, claims.

**Правки (сценарий B)**

1. Правки перенесены в обе версии, текст русской совпадает с файлом пользователя (или — кроме чего и почему).
2. **Что поменялось** — по слайдам.
3. Что не переносил и почему (растянутая PowerPoint таблица, типографика правки).
4. Какие вопросы по деке ещё открыты.
