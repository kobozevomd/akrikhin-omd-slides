# Akrikhin × OMD — презентации в PowerPoint

Дизайн-система слайдов Акрихин × OMD на pptxgenjs и конвейер, которым Codex или Claude собирают презентации в стиле Акрихин:
пересобирают присланную деку, делают новую из текста или таблицы, выпускают русскую и английскую версии из одного кода,
переносят правки из возвращённого файла.

## Установка

Нужны macOS или Linux, node ≥ 18, python3, LibreOffice, poppler, unzip и шрифт Tahoma (на macOS есть из коробки),
для дек с видео — ffmpeg.

```bash
git clone https://github.com/kobozevomd/akrikhin-omd-slides.git
cd akrikhin-omd-slides
./install.sh
```

`install.sh` ставит npm- и python-пакеты, копирует скилл `akrikhin-brand-deck` в `~/.codex/skills` и `~/.claude/skills`
с путём к этой папке и проверяет окружение (`python3 tools/doctor.py`) — чего не хватает, он напишет вместе с командой
установки. На macOS с Homebrew: `brew install node python libreoffice poppler ffmpeg` (`libreoffice` — `--cask`).

Ключи: `--codex` / `--claude` — поставить скилл только для одного агента; `--out ~/Decks` — куда класть готовые деки
(по умолчанию `output/` здесь же); `--skill-only` — переустановить скилл после `git pull`.

## Как пользоваться

Откройте Codex или Claude Code и скажите, например:

- «Собери эту презентацию в стиле Акрихин: ~/Downloads/deck.pptx»
- «Сделай презентацию в стиле Акрихин из этого текста / таблицы»
- «Оформи этот слайд в дизайн-системе Акрихин»
- «Вот моя дека с правками, перенеси их» — после того как агент собрал деку
- «Сделай и английскую версию»

Агент сам найдёт скилл, проверит окружение, соберёт деку, отрендерит слайды, проверит себя и отдаст файлы с отчётом:
что сделано, какие свои правки он предлагает подтвердить, какие цифры исходника не сходятся.

## Что где

- `AGENTS.md` — карта проекта, команды и правила (Codex читает его автоматически).
- `DESIGN.md` — правила дизайн-системы: палитра, типографика, сетка, компоненты, графики.
- `skills/akrikhin-brand-deck/` — скилл: сценарии и задания для исполнителей.
- `lib/` — библиотека, `tools/` — скрипты, `decks/` — код дек, `work/brands/` — брифы, стайлгайд и глоссарий для перевода.

Исходные `.pptx` и всё, что из них выгружено (тексты, картинки, вырезки фото), в репозиторий не входят — они большие и
лежат локально. Поэтому деки серии из `decks/brands/` (Acriol, Clindovit, Azelik, Bobotic, Normobact, Dinobutin,
Akrimycol) без своих исходников не пересобрать; они служат образцами раскладок для новых дек.
