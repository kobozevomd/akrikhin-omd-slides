# Бриф: варианты визуала для слайдов-графиков 6–15 (деки Comprehensive 2027)

Рабочая папка — корень проекта (папка с `AGENTS.md`); пути ниже — от неё.

Роман попросил переделать слайды с данными так, чтобы они были **красивыми и читаемыми**, и предложить по два варианта на слайд — он сам выберет. Для слайдов 2–5 варианты уже сделаны и одобрены по стилю — **они эталон**, делай так же.

## Что прочитать перед работой

1. `DESIGN.md` — палитра, типографика, сетка, компоненты (особенно разделы «Графики» и «Компоненты»).
2. `decks/variants/common.js` — общие помощники для вариантов: `tag`, `yearAxis`, `gridY`, `legend`, `statTile`, `numMark`, `chartData`, константы `TOP/BOT/SIDE/MAIN/MUTED/GRID`, `fmt/pct`.
3. `decks/variants/v03_05.js` и `decks/variants/v02.js` — эталонный код вариантов. Посмотри и их рендеры: `out/render/варианты_3-5/slide-1…6.png`, `out/render/варианты_2/slide-1…3.png`.
4. По своим слайдам: текущая версия `out/render/final/slide-NN.png`, черновик `work/comprehensive/src/slide-NN.png`, данные `work/comprehensive/src/slide-NN.json` (тексты и данные графиков), картинки `work/comprehensive/src/media/`.
5. API библиотеки — `lib/akrikhin.js` (не редактировать). Важное:
   - `s.chart(kind, series, { x, y, w, h, plot: {x,y,w,h}, min, max, ... })` при заданном `plot` возвращает `m` — преобразование «данные → px»: `m.cat(i)`, `m.val(v)`, `m.step`, `m.plot`. С ним рисуешь поверх графика свои подписи, линии среднего, выделения, оси. `chartMap(kind, n, P, lo, hi)` даёт то же самое до рисования графика (чтобы положить заливку под график).
   - Стандартную ось категорий скрывай `extra: { catAxisHidden: true }` и рисуй подписи сама(сам) — так они ровные и крупные.
   - `s.seg(x1,y1,x2,y2,{color,width,dash:'dash'})`, `s.circle({x,y,d,fill,stroke})`, `s.box({..., transparency})`, `s.icon('tb:TbИмя', {x,y,size,color,circle})`.
   - Для `bar` с `percent: true` шкала 0…1 (min 0, max 1).

## Принципы (как в эталоне)

- **Одна история — один акцент.** Главное, о чём говорит заголовок, — малиновым (`C.crimson`) или синим; всё фоновое — приглушённым `MUTED`. Не красить всё подряд.
- **Подписи прямо на графике** (у концов линий, у столбцов) вместо легенд. Легенда — только если без неё никак, и тогда короткая, сверху.
- **Правая колонка с цифрами** (`SIDE`: x 1410, ширина 452) — 1–3 большие цифры-вывода (`statTile`) или комментарий черновика. Слева — карточка с графиком (`MAIN`).
- **Комментарии черновика переносим дословно** (можно исправить опечатки, « - » → « — »). Связь «комментарий ↔ место на графике» — пронумерованными метками `numMark`.
- **Производные цифры** (разница в п.п., во сколько раз, доли, суммы) — можно и нужно, если они помогают прочитать мысль. Считай их в коде из данных, а в сноске добавь «… — расчёт OMD». Придумывать факты, которых нет в данных, нельзя.
- Контент 221…1005 (плашки на этих слайдах нет), сноска-источник 1034 слева, `tag(s, 'Вариант 6А · коротко о приёме')` справа внизу — обязательно на каждом варианте.
- Кегли: подписи данных и оси ≥ 15 px, основной текст ≥ 17, большие цифры 54–64. Числа — с запятой (`fmt`, `pct`).
- Заголовок слайда — как в текущей деке (можно добавить `subtitle`, если это текст черновика).
- Варианты А и Б одного слайда должны быть **по-настоящему разными** (другой тип графика или другая композиция), а не перекраской.

## Концепции по слайдам

### Слайд 6 · «Покупатели совмещают онлайн и офлайн-каналы» (15 типов магазинов × онлайн/офлайн, %)
Комментарий черновика: «Точки продаж FMCG и фармы сохраняют уверенное преобладание офлайн-покупателей» + «Несмотря на лидерство e-Commerce в сегменте непродовольственных товаров по объему трат, даже среди 12-64 в количестве покупателей небольшой перевес остается за офлайном». Источник: Mediascope, BrandPulse 2026. Онлайн-покупки пересчитаны от всего населения.
- **6А — «гантели»**: на каждой строке точка онлайн (blue) и точка офлайн (crimson), соединённые линией; строки отсортированы по разрыву офлайн − онлайн; подписи значений у точек. Строки FMCG/фармы (супермаркеты, аптеки, магазины фиксированных цен) — выделены (жирное название, яркая линия), прочие спокойнее. Справа цифры: например «Аптеки: 89% офлайн vs 38% онлайн», «Супермаркеты: 89% vs 43%», и отдельно — исключение «Салоны связи — единственная категория, где онлайн выше (21% vs 11%)».
- **6Б — «бабочка»**: онлайн-полосы влево от центральной оси, офлайн — вправо, названия категорий по центру или слева; сортировка по офлайну; FMCG/фарма выделены цветом, остальное приглушено; комментарий черновика — над графиком или сбоку.

### Слайд 7 · «Женщины заметно активнее вовлечены в онлайн-покупки» (М/Ж × 7 возрастов; total e-commerce и маркетплейсы, %)
Комментарий: «Особенно активно женщины по сравнению с мужчинами используют маркетплейсы» + «Также видно, что мужчины чаще дополняют маркетплейсы профильными интернет-магазинами». Источник: Mediascope, CrossWeb, январь–июль 2026.
- **7А — пары М/Ж по возрастам**: 7 групп возрастов по оси X, в каждой столбец мужчин (blue) и женщин (crimson) — только маркетплейсы; над парой — разница «+N п.п.». Справа: большая цифра максимального разрыва (Ж 35–44 vs М 35–44) и вторая мысль: средний разрыв «весь e-commerce − маркетплейсы» у мужчин vs у женщин (посчитай: у мужчин ≈ 4,7 п.п., у женщин ≈ 3,0) — это и есть «мужчины чаще дополняют профильными магазинами».
- **7Б — «пирамида»**: горизонтальные полосы, мужчины влево, женщины вправо, возраст в центре; маркетплейсы — заливкой, весь e-commerce — тонким контуром/светлой полосой за ней (видно «добавку» профильных магазинов). Подписи значений.

### Слайд 10 · «Три крупнейших маркетплейса в значительной мере охватывают одних и тех же пользователей» (подзаголовок: «Самая большая доля эксклюзивных пользователей у Ozon»)

## Как сдавать

Твой файл — `decks/variants/vNN_MM.js` (имя дам в задаче), экспорт:

```js
module.exports = { 6: [slide6A, slide6B], 7: [slide7A, slide7B], 9: [slide9A, slide9B] };
```

Каждая функция `(d) => { const s = d.slide({ title, subtitle? }); ... tag(s, 'Вариант 6А · …'); }` добавляет один слайд.

Сборка и проверка (повторять до чистоты):
```bash
node decks/variants_all.js vNN_MM            # → out/варианты_vNN_MM.pptx, печатает предупреждения
python3 tools/validate_pptx.py out/варианты_vNN_MM.pptx
tools/render.sh out/варианты_vNN_MM.pptx     # → out/render/варианты_vNN_MM/slide-N.png
```
Смотри **каждый** PNG (Read) свежим взглядом: читается ли мысль заголовка за 3 секунды; нет ли наложений, обрезанного текста, налезающих подписей; ровные ли отступы; совпадают ли числа с данными. Сравни с эталоном `out/render/варианты_3-5/` — должно быть того же уровня.

Не трогай `lib/`, `DESIGN.md`, чужие файлы в `decks/variants/`, `decks/comprehensive/`.
